Corrección para desarrollo local

1. Sustituye vite.config.js en tu frontend.
2. En el .env del frontend cambia VITE_API_URL=/api.
3. En PowerShell ejecuta Remove-Item Env:VITE_API_URL -ErrorAction SilentlyContinue
   para que una variable de la terminal no reemplace tu .env.
4. Detén Vite con Ctrl+C y reinicia npm run dev.
5. Mantén el backend ejecutándose en http://127.0.0.1:8000.

Prueba http://127.0.0.1:5173/api/health: debe mostrar {"status":"ok"}.
Las peticiones del navegador usarán el origen del frontend y Vite las reenviará a FastAPI.
No hay cambios en SQL ni credenciales. Este proxy funciona con npm run dev; al publicar
se necesita un reverse proxy equivalente o una URL absoluta con CORS correcto.
